# The Entire History of Australia: project files

Everything Claude Code needs to build the finished documentary.

- PROMPT.md: the full build instructions. Start here.
- CLAUDE.md: standing rules Claude Code follows on every run.
- YOUTUBE_DESCRIPTION.md: description draft with acknowledgement, cultural notice and accuracy note (chapters and credits get filled in at the end).
- audio/: final mix (voice + music + effects) and the raw voiceover.
- script/: narration script, shot list and sound cue sheet.
- images/: 97 numbered images and SOURCES.md.
- sfx/ and music/: original Pixabay sound files.
