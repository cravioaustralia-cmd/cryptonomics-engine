### ⚑ Licence flags
- **ALL 15 files are FLAGGED.** Both Mixkit licences allow commercial use and name "YouTube videos", but **neither uses the word "monetised" or "monetized"**. Commercial use is allowed, so monetised YouTube is very likely covered, but the licence never says so in those words.
- **Music: claim risk.** The music licence footnotes YouTube with "If you receive a claim, please forward the details to team@mixkit.co", so Content ID claims are a known possibility. Keep this file and the Mixkit page URLs ready for any dispute.
- **MUS12 is an excerpt (trim + fade) of a Mixkit track.** The music licence forbids "remix them (or incorporate in a music-only track)". This excerpt is used only as a cue inside the film (the End Product), not as a standalone or music-only release, so I treat it as allowed editing. Flagged because the licence does not cover trimming in so many words.

## QC (ffmpeg astats / ebur128 / silencedetect, 10 Oct 2026)
- All 15 files are 48 kHz MP3 at 320 kbps. Metadata and embedded art were stripped (`-map_metadata -1`).
- **No clipping.** Decoded sample maximum is ≤ 0.886 (−1.05 dBFS) in every file, with 0 samples at or above 0.999. True peak is ≤ −1.1 dBTP everywhere.
- **None is empty.** No file has a silence longer than 0.5 s at −60 dB (silencedetect found 0 in every file).
- The checks were by measurement and spectrogram only; nobody has listened to these. Do one listening pass in the edit, especially SFX19 (stand-in) and SFX06 (very short).

## Gaps and notes
- **Rubber stamp (SFX19):** the best real candidate is Freesound #470710, "traditional stamp.wav" by I.fekry (https://freesound.org/people/I.fekry/sounds/470710/). Its page says: "You can copy, modify, distribute and perform the sound, even for commercial purposes, all without the need of asking permission" (Freesound's CC0 wording). It is mirrored on Pixabay as https://pixabay.com/sound-effects/traditional-stamp-44189/ ("traditional stamp I.fekry (Freesound)", Pixabay Content License). Not downloaded: Freesound needs a login, and both sites return 403 to downloads from this machine. If someone downloads the original WAV while logged in, it can replace the stand-in: same filename, 48 kHz conversion, same trim.
- **Marker "squeak" (SFX20):** Mixkit's only marker effect is a felt-tip stroke. If a squeak is required, no CC0 squeak was sourced.
- **Pixabay music** was not used. Mixkit covered all four music IDs, its licence text could be checked word for word on the page, and that licence names YouTube.
