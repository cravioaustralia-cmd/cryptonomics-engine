## Usage notes

- Prefer map / court / portrait stills tied to the VO beats; reject generic bush stock and wrong-corner markers (e.g. Poeppel Corner).
- Guildhall: modern JCPC seat proxy — never caption as the 1914 hearing photograph.
- Todd: instruments / remeasurement only — never “the man who marked the first line”.
- Longitude true-vs-surveyed: Claude should animate SVG/MG overlays (offset km callout), not rely on a globe photo alone.
- Area stamps: `~1,300 km²` / over 1,000 — never an absolute single-decimal claim.
- CC BY / BY-SA stills: keep attribution in this file; share-alike applies if a still itself is adapted as a standalone work — MG overlay on a dimmed underlay for the Short is the intended use.
- OSM-derived anomaly map: credit OpenStreetMap contributors + SCHolar44.
