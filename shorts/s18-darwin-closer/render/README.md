# Render — s18-darwin-closer (MAP EXPLAINER)

SVG + `renderFrame(t)` + Playwright + ffmpeg. **No Remotion.** Reuses `shorts/shared/render/engine.js` (helpers) and its Playwright install.

## Files
- `frame.html` — page: 3D-tilted map plane (`#mapwrap > #plane`, CSS perspective) + upright SVG layers (`#fx`, `#photos`, `#ui`).
- `scenes.js` — the whole Short: camera track (monotone-cubic keyframes over centre/zoom/tilt, never static), satellite/topo + georeferenced MODIS basemaps, parchment + thick white-glow borders, self-drawing routes with ticking km callouts, capital pins, 3D extruded labels, distance ladder, raid formations, bomb-count columns, captions (~70%).
- `geo.js`, `assets/` — generated by `tools/prep_assets.py <dir with Natural Earth geojson>`.
- `capture.mjs` — `node capture.mjs frames 4` (parallel workers → `out/frames/`), `node capture.mjs stills 1.5,8.3` (review PNGs).
- `mix.mjs` — VO static gain + apad → float amix with music envelope + SFX → master limiter → **two-pass loudnorm on master only** (−14 LUFS). No VO loudnorm before the mix.
- `tools/sheet.py` — contact sheet.

## Build
```bash
python3 render/tools/prep_assets.py /path/to/naturalearth   # only if assets change
node render/mix.mjs
node render/capture.mjs frames 4
ffmpeg -framerate 30 -i out/frames/f_%05d.jpg -i out/final-mix.wav -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest -movflags +faststart out/s18-darwin-closer.mp4
```
Timing: Whisper (faster-whisper small.en) word timings of held `audio/vo.mp3` → `../transcript.json` (spellings normalised to the script).
