# Render — s19-emu-war (standard Skylab: photo underlay + premium MG — NOT map-explainer)

SVG + `renderFrame(t)` + Playwright + ffmpeg. **No Remotion.** Reuses `shorts/shared/render/engine.js` (easing, caption grouping) and the shared renderer's Playwright install.

## Files
- `frame.html` — page: persistent `#photos` layer (full-bleed WA stills, blurred period fills, framed 1932 prints, film grain) + per-frame `#mg` SVG layer.
- `scenes.js` — the whole Short (15 shots timed to Whisper word timings): frame-1 hook card `THE EMU WAR` on a soldiers-vs-emu split with a Lewis-gun blueprint registered on the real 1932 print; `1932` stamp; `~20,000` counter + vector emu flock; `WESTERN AUSTRALIA` chip + WA locator glyph (Merredin pin); McMurray/O’Halloran nameplate; self-drawing Lewis gun (spinning pan magazine, muzzle flash, ejected brass); `PROBLEM 1/2/3` odometer plate — scatter burst + hunting reticle, speed streaks + speedo `>40 KM/H`, running emu with dust puffs (no gore); NOV→DEC 1932 calendar flip, .303 brass rain + pan magazines; stylised 1932 newsprint props; recall slip + stamp; `MAJOR MEREDITH` brass plaque + soft quote-mark gesture; lock-on brackets on real emus + marching emu division over a globe; loop whip back to the frame-1 hook. Karaoke captions in the ~70 % band.
- `assets/` — generated by `tools/prep_assets.py` from `../images/` (9:16 crops, blurred fills, 2× prints, grain) + Montserrat (OFL).
- `capture.mjs` — `node capture.mjs frames 4` (parallel workers → `out/frames/`), `node capture.mjs stills 1.5,8.3` (review PNGs).
- `mix.mjs` — VO static gain + apad → float amix with Curiosity bed (static −23 dB, ~4 dB under s18's bed, small gap lifts) + SFX → master limiter → **two-pass loudnorm on master only** (−14 LUFS / −1.5 dBTP). No VO loudnorm before the mix.
- `tools/sheet.py` — contact sheet.

## Build (from the episode dir)
```bash
python3 render/tools/prep_assets.py        # only if images change
node render/mix.mjs
node render/capture.mjs frames 4
ffmpeg -framerate 30 -i out/frames/f_%05d.jpg -i out/final-mix.wav -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest -movflags +faststart final/s19-emu-war.mp4
```
Timing: Whisper (faster-whisper small.en) word timings of held `audio/vo.mp3` → `../transcript.json` (spellings normalised to the script; a trailing zero-length hallucination after 40.66 s dropped).
